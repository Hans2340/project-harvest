# Dark Ages UI pack: team notes

- **Source:** Dark Ages UI Pixel Art Asset Pack v1.0 by Hypnobius (https://hypnobius.itch.io/). See `LICENSE.txt`.
- **Keep the repo private** while these files are in it (no redistribution allowed).
- `ui_tilesheet.png` is the pack's `32x32-Tilesheet.png`, renamed.
- Regions used by the game are listed in `scripts/ui/ui_skin.gd`, so add new pieces there.
- Don't scale below the original size (32 px tiles); our 640×360 base resolution keeps it 1:1.
- Not used yet: parchment panels, health/stamina/mana bars, decorative corners and dividers,
  gold/grey diamond icons (page dots), the alert icon.
