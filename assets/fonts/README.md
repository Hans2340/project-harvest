# Fonts

- `Micro5-Regular.ttf`: **Micro 5** by the Soft Type Project Authors
  (https://github.com/scfried/soft-type-micro), from Google Fonts. SIL Open Font License 1.1
  (`OFL.txt`): free to use and ship in the game.
- A true pixel font: its native size is **11** (5 px capitals), where every glyph sits on the
  pixel grid. Use 11, or 22 for 2x headings, never sizes in between.
- Imported with antialiasing, hinting and subpixel positioning off so it stays crisp when the
  640x360 game is scaled up. Set as the default font in `resources/ui_theme.tres`.
